# 4.2.1 Levantamento de Requisitos

## Como os requisitos foram levantados

Os requisitos do Gap Hub foram levantados em dois passos. Primeiro, uma **entrevista** com o Gustavo, o líder dos adolescentes do Gap, sobre como o agendamento das atividades funciona hoje. Depois, uma **conversa** com o Gabriel, um dos adolescentes que frequenta o Gap. E finalmente, uma **observação** de como esses agendamentos funcionam na prática (no aplicativo de mensagens), vendo tanto o lado da liderança quanto dos adolescentes.

## Da fala à necessidade
| # | Fala | O que é | Necessidade por trás |
|---|---|---|---|
| F1 | "Quem é da liderança faz a contagem de quem vai" (Gustavo) | necessidade | registrar quem vai em cada evento |
| F2 | "Temos que ficar avisando quando a data do evento está chegando" (Gustavo) | necessidade | avisar se um evento está próximo |
| F3 | "Nós pedimos as informações de quem vai sempre que temos um evento novo, pois não temos elas guardadas em um lugar definitivo" (Gustavo) | **necessidade implícita**: reclamação | armazenar os dados de cada adolescente |
| F4 | "Quem é da liderança programa os eventos e encontros" | necessidade | cadastrar e remover eventos |
| F5 | "Seria legal se desse pra ver todos os eventos em um lugar só" | solução | o sistema exibir os eventos cadastrados |
| F6 | "Também seria bacana se desse se increver num evento só clicando em um botão" | solução | o adolescente poder se inscrever facilmente em um evento |

## Histórias de usuário

| # | História de usuário | Veio de |
|---|---|---|
| HU01 | Como **líder** quero **cadastrar e remover eventos**, para **os adolescentes poderem increver-se neles** | F5 |
| HU02 | Como **líder** quero **visualizar quem vai em cada evento** para **fazer uma melhor organização** | F1 |
| HU03 | Como **líder** quero **ter acesso aos dados dos adolescentes** para **não precisar ficar pedindo eles o tempo todo** | F3 |
| HU04 | Como **adolescente** quero **increver-me em eventos** para **garantir minha participação** | F5 |
| HU05 | Como **adolescente** quero **ser avisado quando um evento estiver próximo** para **não deixar de participar dele** | F2 |

## Requisitos funcionais

| # | Nome | Requisito  | Veio de |
|---|---|---|---|
| RF01 | Cadastrar evento | O sistema deve permitir que o líder cadastre um evento | HU01 |
| RF02 | Remover evento | O sistema deve permitir que o líder remova um evento cadastrado | HU01 |
| RF03 | Consultar inscrições | O sistema deve permitir que o usuário consulte as incrições de um evento | HU02 |
| RF04 | Consultar dados | O sistema deve permitir que o líder consulte os dados de um adolescente | HU03 |
| RF05 | Increver | O sistema deve permitir que o adolescente se increva em um evendo cadastrado | HU04 |
| RF06 | Avisar data de evento | O sistema deve avisar o adolescente quando faltar 1 dia para um evento no qual ele esteja inscrito | HU05 |
| RF07 | Exibir eventos | O sistema deve exibir os eventos cadastrados | F5 |
| RF08 | Armazenar dados | O sistema deve armazenar os dados de um usuário | F3 |
